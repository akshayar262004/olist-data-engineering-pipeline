# Olist Data Engineering Pipeline

## Project Description
A Python-based pipeline to process and validate Olist e-commerce datasets.

## Tools Used
Python, Pandas, PyYAML, Jupyter Notebook, Pytest and GitHub.

## Main Features
- Read multiple CSV files.
- Apply column mapping using YAML.
- Validate data and identify duplicates and missing values.
- Separate invalid records into `bad_records.csv`.
- Handle errors using custom exceptions.
- Maintain pipeline logs.
- Track processed files using a manifest.
- Perform unit testing.

## Project Outputs
- Cleaned CSV files
- Bad records CSV
- Pipeline log file
- Processing manifest
